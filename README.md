# My To-Do List

A simple, clean, and responsive to-do list web app built with HTML, CSS, and vanilla JavaScript.

## Features

- Add a new task from the input field
- Press Enter or click the Add Task button to save a task
- Prevent empty tasks from being added
- Mark tasks as complete or incomplete with a checkbox
- Edit existing tasks
- Delete individual tasks
- Clear all completed tasks in one click
- View the remaining pending task count
- Save task data in browser localStorage so it persists on refresh and restart
- Responsive layout for desktop, tablet, and mobile

## Project Structure

```text
todo-app/

```

## How to Run

1. Open the project folder in a browser.
2. Open `index.html` directly in your browser.
3. Start adding tasks.

No installation or backend setup is required.

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage

## App Behavior

The app includes:

- A task input field and Add Task button
- A checkbox for completing tasks
- A strikethrough effect for completed tasks
- Edit and Delete actions for each task
- A task counter showing how many tasks remain
- A Clear Completed button to remove finished tasks
- Persistence using `localStorage`

## Notes

This project is intentionally built without frameworks or external libraries so it stays beginner-friendly and easy to understand.
